# ai-customer-support-agent

A full-stack AI-powered customer support chatbot using:

- LangChain
- FastAPI
- React
- ChromaDB
- Groq API
- RAG Architecture

---

# Features

- AI customer support chatbot
- Retrieval-Augmented Generation (RAG)
- Semantic search
- Custom knowledge base
- React frontend
- FastAPI backend
- Chroma vector database
- Groq LLM integration

---

# Tech Stack

## Backend
- Python
- FastAPI

- ChromaDB

# Setup Backend

```bash
cd backend

venv\\Scripts\\activate

pip install -r requirements.txt

uvicorn api:app --reload
```

---

# Setup Frontend

```bash
cd frontend

npm install

npm run dev
```
